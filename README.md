# JM 漫画下载器 v2.9.1

一个面向 Windows x64 的原生桌面漫画下载工具。程序使用 Python、
PySide6 Essentials 与 Qt Widgets，支持搜索、章节选择、任务恢复、收藏
同步、本地漫画管理，以及 PDF、CBZ 和仅图片三种保存方式。

v2.9.1 补全本地章节管理：离线检查每章图片与打包状态，按原格式重建，
选择性创建固定章节修复任务，按章安全删除，以及主动识别可唯一映射的
旧版图片目录。所有账号相关本地数据仍保存在程序目录，并使用 Windows
DPAPI CurrentUser 加密。

## 开箱即用版

1. 下载 `JM-Downloader-v2.9.1-Windows-x64.zip` 及同名 `.sha256` 文件。
2. 在 PowerShell 运行
   `Get-FileHash .\JM-Downloader-v2.9.1-Windows-x64.zip -Algorithm SHA256`，
   确认结果与校验文件一致。
3. 解压 ZIP，保持目录结构完整，然后双击 `JM-Downloader.exe`。

发行目录包含两个入口：

- `JM-Downloader.exe`：正式版，不显示终端窗口。
- `JM-Downloader-Debug.exe`：调试版，启动异常时可查看终端输出。

请整体移动 `JM-Downloader` 文件夹，不要只移动 EXE，也不要遗漏
`_internal`。程序不会把状态写入 AppData、注册表或数据库。

## 下载漫画

1. 进入「搜索与下载」，打开「下载任务」。
2. 输入纯数字或带 `JM` 前缀的编号并提交。
3. 程序在后台读取章节目录并打开章节确认框。单章漫画也需要确认，
   用于避免误触和意外重复下载。
4. 对话框默认不选择章节；勾选后确认。已完整下载章节默认不可选，
   如需重下请开启「包含已下载章节」。
5. 一次可以选择任意数量章节；程序按原顺序每最多 10 章自动拆分为
   多个任务。同一本漫画严格串行，不同漫画仍可并行。

发现队列重叠或其他可预检问题时，本批任务一个也不会创建；对话框会
保留选择并指出问题章节，由用户调整后重试。只有下载期间才能发现的
远端坏章会让当前子任务失败，其他非重叠子任务仍会继续执行。

下载默认使用 jmcomic 的异步下载引擎，也可以在设置中切换为同步线程
引擎。暂停与取消是协作式停止：程序不再发起后续请求，但已经发出的
请求不保证立即中断。有效图片会保留，缺失或损坏图片在继续时重下。

每个任务会锁定创建时的固定章节、引擎、API 路线、打包格式、图片格式、
输出目录和并发设置；全局设置之后发生变化，不会改变已有任务的恢复与
重试行为。只有全部章节图片通过完整性检查，任务才会进入打包或完成阶段。

### 保存方式

- **分章 PDF（默认）**：每章生成一份 PDF。
- **CBZ**：每章生成一份 CBZ，内部图片按自然顺序保存。
- **仅图片**：只保留验证完成的图片，不生成打包产物。

图片格式可以选择 JPG 或 PNG。PDF 和 CBZ 共用设置中的「打包产物目录」；
内部继续使用兼容字段 `pdfs`/`pdf_directory`，不会破坏旧设置和旧任务。

### API 路线

设置页可以选择「自动选择」或固定 API 路线，并可主动点击「测试路线」。
路线设置同时影响下载、搜索、账号和收藏。固定路线失灵时，请切回
「自动选择」后重试；程序不会在后台自动探测或改写 `option.yml`。

## 搜索漫画与搜索历史

「搜索结果」支持综合、作者、标签和精确 JM 号查询。普通搜索最多展示
前 1000 条结果；上游未返回的标题、作者、标签或章节信息不会被程序猜测。

成功搜索后会记录搜索历史；空结果也属于成功搜索，校验失败、网络失败
和已被新请求取代的迟到结果不会记录。历史最多 50 条，同类型去重并按
最近使用排序。点击输入框可以选择或单独删除记录，设置页可清除全部历史。
`search_history.dat` 使用 DPAPI 加密，换电脑或换 Windows 用户后通常不能
解密，并会按损坏恢复规则降级为空历史。

搜索卡片在确认章节前不会创建下载任务。单章显示「确认下载」，多章显示
「章节选择」；已有任务显示「查看任务」。

## 账号、密码记忆与我的收藏

登录不是搜索和下载的前提。账号会话保存在加密的 `account.dat`，收藏完整
快照保存在 `favorites.dat`。启动程序只恢复本地状态，不会自动联网。

「记住密码」默认关闭。开启前会显示安全警告；用户确认并成功登录后，
账号和密码才会写入 DPAPI 加密的 `credentials.dat`。会话失效时程序只填充
登录框，不会自动提交。关闭该选项或执行「退出登录」会立即删除记忆凭据。
DPAPI 可防止直接读取静态密文，但不能防止当前 Windows 用户会话中的恶意
程序读取数据。

「我的收藏」支持：

- 手动完整同步，失败时保留上一次完整快照。
- 切换收藏夹、分页，以及按标题、作者或 JM 号本地筛选。
- 按收藏时间或更新时间从远端重新同步排序。
- 从搜索卡片选择收藏位置。
- 使用「管理收藏夹」新建收藏夹、删除已确认为空的自建收藏夹。
- 在自建收藏夹之间移动，或移回“未分类（默认位置）”。

远端写入不会自动重试。写入成功但刷新失败时会保留旧快照并提示手动同步；
结果无法确认时也应先手动同步。当前不支持取消收藏或重命名收藏夹。

## 本地漫画库

本地漫画库扫描当前图片目录和打包产物目录，支持：

- 按 JM 号或按名称检索。
- 按下载时间或名称排序，默认下载时间从新到旧。
- 筛选全部、有图片或有打包产物的项目。
- 打开图片目录或打包产物文件夹。
- 单本或多选批量删除图片、全部 PDF/CBZ，或者全部本地文件。
- 对受管布局打开「管理章节」，离线检查并按章处理。
- 对没有清单的旧版图片布局主动点击「识别章节」。

批量删除逐本取得占用权限并汇总部分失败；每本漫画仍使用暂存与回滚语义。
正在下载或执行本地操作的漫画不会被破坏。删除打包产物会删除受管的 PDF
与 CBZ，但不会触碰旧版本生成的旧整本 PDF `PDFs/JM号.pdf`。漫画级
「删除图片」会保留章节清单记录，方便之后检查和重新下载。

新布局的标题、章节和下载时间来自 `Pictures/JM号/.jm-chapters.json`。
清单为每章记录 PDF、CBZ 或仅图片原格式；旧清单证据不足时必须由用户
确认，当前设置只作为确认框默认值，不会静默覆盖原格式。检查章节完全
离线：图片完整但打包产物缺失或损坏时在本地重建；图片缺失或损坏时，
只有用户选择「修复所选」才创建固定章节强制重下任务。

旧清单没有下载时间时回落目录修改时间。没有清单的旧布局不会在页面扫描
时联网猜测；用户主动点击「识别章节」并确认联网后，程序只迁移与远端
目录能够精确、唯一对应且通过路径安全检查的项目。歧义、遗漏、额外文件
或中途失败都会保持原布局，不提供模糊匹配，也不迁移旧整本 PDF。

## 设置与运行时文件

设置页包含下载引擎、API 路线与测试、保存方式、图片格式、并发设置、
多章下载行为、图片目录、打包产物目录、记住密码、日志、启动页面、窗口
尺寸和主题。新设置立即影响之后创建的新任务；已有任务使用自己的快照。

| 路径 | 内容 |
|------|------|
| `Pictures/` | JPG/PNG 漫画图片与章节清单 |
| `PDFs/` | 分章 PDF 或 CBZ 打包产物 |
| `logs/app.log` | 运行日志 |
| `settings.json` | 应用设置 |
| `tasks.json` | 未完成和失败任务 |
| `account.dat` | DPAPI 加密的账号会话 |
| `favorites.dat` | DPAPI 加密的收藏完整快照 |
| `search_history.dat` | DPAPI 加密的搜索历史 |
| `credentials.dat` | 可选的 DPAPI 加密登录凭据 |
| `option.yml` | JMComic 底层配置，正常使用时不会改写 |

设置、任务与四类加密数据均采用原子写入；损坏输入会保留为对应的
`.corrupt-*` 文件。程序目录内的输出路径保存为相对路径，用户明确选择的
外部目录保存为绝对路径。

## 源码版运行

源码项目要求 64 位 Windows 和 Python 3.10 至 3.14。推荐运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\setup.ps1
.\.venv\Scripts\python.exe desktop.py
```

`desktop.py` 是唯一生产入口。项目虚拟环境、运行依赖版本和 PyInstaller
构建依赖均由仓库文件固定。

## 构建发行包

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\build.ps1
```

脚本运行完整测试，构建 PyInstaller `onedir` 正式版与调试版，执行启动和
离线后端验证，并生成：

- `release/JM-Downloader-v2.9.1-Windows-x64.zip`
- `release/JM-Downloader-v2.9.1-Windows-x64.zip.sha256`

构建不会覆盖 v2.1.0、v2.2.0、v2.3.0、v2.4.0、v2.5.0、v2.5.1、
v2.7.0、v2.8.0 和 v2.9.0 历史发行包。设置、任务、账号、收藏、搜索
历史、记忆凭据、日志、下载内容和临时文件均不得进入 ZIP。
